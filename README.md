# AnimeRate

AnimeRate is a web platform that lets you **browse, rate, and track anime** (all in one place).

Whether you're binge-watching or casually exploring, AnimeRate helps you stay organized and expressive about what you watch.

---

## Status

⚠️ **Currently under development** ⚠️

The previous version has been taken down.  
Why? Because it sucked!

This is a complete rebuild — **faster, cleaner, and way better.**

---

## Features (Planned & In Progress)

- Browse anime  
- Rate anime  
- Create and manage watchlists  
- Track progress:
  - Completed  
  - Watching  
  - Plan to watch  
- User authentication  
- Responsive UI ( so you can use it on your phone PRACTICALLY !)

---

## Vision

AnimeRate is built with the idea of making anime tracking:
- Simple  
- Personal  
- Efficient  

No clutter. No unnecessary complexity. Just a smooth experience.

## Why the Rebuild?

Because the old version wasn’t **practically usable**.  
This version is being built with better design, better code, and logic.
